# Security open items — Reference

> Open security findings, each verified against the current code. Accepted designs live in [docs/security-posture.md](../../docs/security-posture.md), which is the only authority for deliberate trade-offs; this file does not restate them. A fixed finding is deleted from here rather than kept as history.

## Open findings

Deliberate trade-offs that look like bugs are not listed here — open signup, the clear-text CLI credential, process-local state, permanent audit rows, the workspace-wide read baseline and the anonymous machine endpoints are in [docs/security-posture.md](../../docs/security-posture.md). A finding that spans subsystems appears once, under the symbol that owns the decision.

| Location (symbol) | Finding | Impact | Suggested direction |
| --- | --- | --- | --- |
| `backend/plugin/db/util/ssl.go` — `GetTLSConfig` | `verify_tls_certificate=false` (the default) sets `InsecureSkipVerify`, with no warning | target-database TLS is unauthenticated encryption; anyone on the path can intercept | verify by default; make downgrading an explicit UI action |
| `backend/plugin/idp/oauth2/oauth2.go` — `NewIdentityProvider` | `skip_tls_verify` goes straight into `InsecureSkipVerify`; the form defaults it off and warns, but nothing prevents enabling it | a MITM can forge the userinfo subject and take over an account bound to that subject | keep the default and warning; to close it, refuse `skip_tls_verify=true` by deployment policy |
| `backend/plugin/db/util/ssh.go` — `getSSHClient` | with no `ssh_private_key`, the tunnel dials the process's own `SSH_AUTH_SOCK` and offers all of the operator's agent keys to the user-supplied `ssh_host` | public-key enumeration; on a match, authentication as the operator (host-key verification is separate and enforced) | remove the agent fallback, or make it an explicit setting |
| `backend/component/llm/fetcher.go` — `ValidateBaseURL` | accepts any absolute `http`/`https` URL with a host: no private-address rejection, no HTTPS requirement | whoever can configure a profile can use the server as an internal-network probe carrying the API key, and plain `http` sends the key in the clear | reject obvious internal ranges and non-loopback plain `http`; requiring the key whenever `base_url` changes already blocks reusing a stored key |
| `backend/component/llm/stream.go` — `llmHTTPClient` | the shared client has no `CheckRedirect` | an upstream can answer 302 to another host and take the Bearer key with it | add `CheckRedirect` and limit redirects to the same host |
| `backend/server/pprof.go` — `registerPprof` | `/debug/pprof/*` is gated only by `RuntimeDebug`, which `SettingService.UpdateDebugConfig` (`settings.update`) can toggle, and it has no authentication | anyone holding `settings.update` can expose heap, goroutine, cmdline and profile anonymously; the heap holds the resident JWT signing key and decrypted credentials | give pprof its own switch, bind it to loopback or require administrative authentication, and warn when enabling it at runtime |
| `backend/api/auth/auth.go` — `AccessTokenCookieName` | the session cookie is still `access-token`: no `__Host-` prefix, and `GetTokenFromHeaders` accepts the first same-name cookie | a controllable sibling subdomain under a shared parent can plant a `Domain=` cookie and hijack `/v1` | use `__Host-access-token` over HTTPS and reject requests carrying more than one same-name cookie |
| `backend/server/csrf.go` — `csrfProtectionMiddleware` | duplicates the cookie name in its own `accessTokenCookieName`, with no compile-time link to `auth.AccessTokenCookieName`; `csrf_test.go` hard-codes the same literal | a rename on either side silently disables CSRF, and the test cannot catch it | share one constant; add a drift test |
| `backend/api/v1/instance_service.go` — `dataSourceConnectionError` | echoes the driver's own error, with no host allow/deny list | an instance writer can probe arbitrary host:port and fingerprint services from the differing errors | normalize the message and offer a host policy |
| `backend/store/oauth_client.go` — `ListOAuthClients`, `DeleteOAuthClient`, `TouchOAuthClient` | Connected apps manages authorizations, not client registrations: the list and delete have no callers, `last_used_at` is written but never read, and registrations have no total cap | a registration flood can be cleaned up only with SQL and the UI shows no registrations; enabling delete before adding the missing grant foreign key would leave orphan authorizations | add a registration list/delete or a capacity/retention policy, and add the foreign key or cascade before enabling deletion |
| `backend/component/audit/audit.go` — `ResolveActor` | for an anonymous request the actor falls back to fields the request supplies (`user.name`, `email`) | an attacker chooses the actor text written into the permanent ledger, so attribution is unreliable | record the source address and leave the actor empty for anonymous requests |
| `backend/component/audit/audit.go` — `IsSensitiveAuditField` | the name list covers `sslkey` and `sslcert` but not `ssl_ca` | a PEM pasted into `ssl_ca` (possibly including a private key) is stored in the ledger forever | add `sslca`; longer term, use proto sensitive annotations plus value-pattern scanning |
| `backend/common/crypto/crypto.go` — `Encrypt` / `Decrypt` | the GCM additional data is nil, so a ciphertext is not bound to its field or row | database write access can move one instance's ciphertext into another's row and hand that credential to the other connection | bind an AAD (instance and field identifier) |
| `backend/plugin/db/mysql/mysql.go` — `getMySQLConnection`; `backend/plugin/db/starrocks/starrocks.go` | the tunnel dial protocol name is `uuid.NewString()[:8]` (32 bits) and registration silently overwrites an existing entry | concurrent tunnels can collide and cross two instances' dials (the name is deregistered on close); the probability is low but non-zero | use the full UUID as the protocol name |
| `backend/server/grpc_routes.go` — the four anonymous OAuth routes | each route calls `oauthEndpointMiddleware`, which builds its own limiter store, so the per-address budget (10/s, burst 20) exists four times over | an anonymous caller can drive the anonymous OAuth surface at four times the intended ceiling | decide whether to share one limiter (tightening the ceiling four-fold) or keep per-route budgets and document them as such |
| `backend/api/v1/role_service.go` — `UpdateRole` | shrinking the permissions of a role that is still bound has no affected-binding warning; `DeleteRole` does refuse a still-bound role | an administrator can silently strip a bound role's permissions and lock its users out | return the affected binding/user count and require confirmation |

## Re-checking an item

Re-read the named symbol and all of its callers before treating a row as current. Fixing a finding either deletes its row (a real fix) or moves the accepted trade-off into [docs/security-posture.md](../../docs/security-posture.md) (a deliberate decision); do not leave the fixed row here.
